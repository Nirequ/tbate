# TBATE RPG - The Beginning After The End

RPG roguelike игра в Roblox по мотивам новеллы "The Beginning After The End".

## Описание

Это система создания персонажей для RPG игры. Игрок заходит на отдельный сервер (1 игрок), создает персонажа, выбирает расу и внешность, после чего телепортируется на основной игровой сервер.

## Возможности

### Система персонажей
- **3 слота персонажей**: первый бесплатный, 2-й и 3-й за 100 Robux каждый
- **3 расы**:
  - **Человек** - сбалансированная раса (рост 1.0x)
  - **Эльф** - высокая раса с длинными ушами (рост 1.15x)
  - **Дварф** - низкорослая крепкая раса (рост 0.75x)
- **Кастомизация внешности**:
  - Выбор прически
  - Выбор одежды (рубашка и штаны)
  - Цвет кожи и волос

### Технические особенности
- Сохранение персонажей через DataStore
- Автоматическая модификация модели персонажа в зависимости от расы
- Телепортация на основной сервер после создания персонажа

## Установка и запуск

### Требования
- [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0 или выше
- Roblox Studio

### Сборка проекта

1. Соберите проект:
```bash
rojo build -o "TBATE.rbxlx"
```

2. Откройте `TBATE.rbxlx` в Roblox Studio

3. Запустите Rojo сервер для live sync:
```bash
rojo serve
```

## Настройка

### Настройка ID основного места
В файле `src/shared/CharacterConfig.lua` установите ID вашего основного игрового места:
```lua
CharacterConfig.MAIN_GAME_PLACE_ID = YOUR_PLACE_ID
```

### Добавление причесок и одежды
В `CharacterConfig.lua` добавьте Asset ID из каталога Roblox:
```lua
CharacterConfig.HAIRSTYLES = {
    {Name = "Короткие волосы", AssetId = 123456789},
    -- Добавьте больше причесок
}
```

### Настройка Game Pass для слотов
В `CharacterService.lua` настройте проверку Game Pass для разблокировки слотов 2 и 3.

## Как это работает

1. **Игрок заходит в игру** → Показывается экран выбора слота
2. **Выбор слота** → Если персонаж существует - загружается, если нет - открывается редактор
3. **Создание персонажа** → Игрок выбирает расу, прическу, одежду
4. **Подтверждение** → Персонаж сохраняется в DataStore
5. **Загрузка** → Модель персонажа модифицируется согласно расе
6. **Телепортация** → Игрок телепортируется на основной сервер

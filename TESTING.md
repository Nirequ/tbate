## Инструкция по тестированию системы создания персонажей

### Шаг 1: Сборка проекта

1. Откройте терминал в папке проекта
2. Выполните команду:
```bash
rojo build -o "TBATE.rbxlx"
```

### Шаг 2: Открытие в Roblox Studio

1. Откройте файл `TBATE.rbxlx` в Roblox Studio
2. Включите тестовый режим DataStore:
   - **Home → Game Settings → Security**
   - Включите **Enable Studio Access to API Services**

### Шаг 3: Тестирование

1. Нажмите **Play** (F5) в Studio
2. Вы должны увидеть:
   - Экран выбора слота с 3 слотами
   - Первый слот разблокирован
   - Слоты 2 и 3 заблокированы (с кнопкой разблокировки)

3. Нажмите "СОЗДАТЬ" на первом слоте
4. Откроется редактор персонажа:
   - Выберите расу (Человек/Эльф/Дварф)
   - Выберите прическу
   - Выберите одежду
   - Нажмите "ПОДТВЕРДИТЬ"

5. Персонаж будет создан и применен к вашей модели
6. Вы увидите сообщение о завершении (телепортация отключена для тестирования)

### Шаг 4: Проверка сохранения

1. Остановите игру (Shift+F5)
2. Запустите снова (F5)
3. Теперь на первом слоте должна быть кнопка "ВЫБРАТЬ" вместо "СОЗДАТЬ"
4. Нажмите "ВЫБРАТЬ" - персонаж загрузится из сохранения

### Проверка консоли

Откройте **View → Output** и проверьте сообщения:
- `=== TBATE RPG Server Starting ===`
- `CharacterService initialized`
- `=== TBATE RPG Client Starting ===`
- `Slot selection UI ready`
- `Character created successfully!`

### Возможные проблемы

**Проблема**: UI не появляется
**Решение**: Проверьте Output на ошибки, убедитесь что все модули загружены

**Проблема**: DataStore не сохраняет
**Решение**: Включите "Enable Studio Access to API Services" в настройках

**Проблема**: Персонаж не меняется
**Решение**: Проверьте что HumanoidDescription применяется корректно

### Следующие шаги

После успешного тестирования:
1. Опубликуйте игру на Roblox
2. Создайте второй Place для основной игры
3. Получите Place ID и обновите `CharacterConfig.lua`
4. Создайте Game Pass для разблокировки слотов 2 и 3
